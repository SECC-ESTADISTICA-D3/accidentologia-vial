Preparar la base para publicar

Esta herramienta toma la base completa de accidentología y genera una copia que conserva únicamente las columnas estadísticas que usa el sitio. Los datos personales de víctimas y causantes se descartan antes de generar el archivo. Todo el proceso ocurre en esta computadora: nada se envía a internet.

Arrastrá acá la base completa, o elegila desde tu equipo.

El archivo que se descarga se llama accidentologia.xlsx. Copialo dentro de la carpeta datos/ del sitio, pisando el anterior, y publicá los cambios.
